# Studio Lite — محاسبة لايت للاستوديوهات

برنامج ويب عربي خفيف لاستوديوهات التصوير:
العرسان، نقطة البيع، الطلبيات وحالتها، الدفعات (سندات القبض)، كشف حساب تفصيلي، أعمار الذمم، ومطالبة على واتساب.

- لا يحتاج أي مكتبات: **Node.js 18+ فقط**.
- البيانات في ملف واحد `db.json` داخل مجلد البيانات، مع نسخة احتياطية يومية تلقائية (آخر 60 يوم).
- كل استوديو = نسخة مستقلة (بياناته، منفذه، ورابطه الخاص). نفس الكود يخدم كل النسخ.
- الرابط خاص: يحتاج تسجيل دخول، ومحجوب عن محركات البحث (noindex + robots.txt).

## الصلاحيات
| | موظف | مدير |
|---|---|---|
| إضافة/تعديل عرسان، طلبيات، دفعات | ✅ | ✅ |
| كشف الحساب وأعمار الذمم والطباعة | ✅ | ✅ |
| تعديل طلبية | طلبياته فقط | ✅ |
| إلغاء طلبية/سند، حذف عريس | ❌ | ✅ |
| الخدمات والأسعار، المستخدمين، الإعدادات، النسخ الاحتياطي | ❌ | ✅ |

## التشغيل على السيرفر (مرة واحدة)

1. **الدومين**: في لوحة الأنظمة الموثوقة أضف سجل `A` باسم `solo` يشير إلى `13.140.207.88`.

2. **السحب من GitHub** (نفس طريقة مشاريعك الثانية):
   ```bash
   cd /opt
   git clone https://github.com/alshaheedlib-beep/studio-lite.git
   cd studio-lite
   ```

3. **إنشاء نسخة استوديو Solo**:
   ```bash
   sudo bash deploy/new-studio.sh solo 3101 solo.alshaheed.ps "Solo" "محمد:mohammad,احمد:ahmad,محمود:mahmoud"
   ```
   السكربت يطبع كلمة مرور المدير — احفظها.

4. **التحديث التلقائي من GitHub** (كل دقيقة يفحص ويعيد تشغيل كل النسخ):
   ```bash
   (crontab -l 2>/dev/null; echo "* * * * * /opt/studio-lite/deploy/auto-pull.sh >> /var/log/studio-lite-pull.log 2>&1") | crontab -
   ```

بعدها أي تعديل ترفعه على GitHub يوصل للسيرفر لحاله خلال دقيقة.

## بيع نسخة لاستوديو جديد
```bash
cd /opt/studio-lite
sudo bash deploy/new-studio.sh nour 3102 nour.alshaheed.ps "استوديو نور"
```
(أضف سجل DNS للرابط الجديد أولاً). النسخة الجديدة تبدأ فاضية: بدون عرسان وبدون موظفين، والخدمات أمثلة يعدّلها صاحب الاستوديو.

## أوامر مفيدة
```bash
pm2 ls                          # كل النسخ الشغالة
pm2 logs studio-solo            # سجل نسخة
pm2 restart studio-solo
ls /var/lib/studio-lite/solo/backups   # النسخ الاحتياطية اليومية
```

## ملاحظات محاسبية
- **الرصيد** = رصيد افتتاحي + الطلبيات − الدفعات (الملغاة لا تُحسب).
- **أعمار الذمم**: الدفعات تُخصم من الأقدم أولاً (FIFO)، والمتبقي يتوزع على 0-30 / 31-60 / 61-90 / +90 يوم، محسوب من تاريخ الطلبية أو تاريخ المناسبة (تختار).
- لا يوجد حذف للطلبيات والسندات — يوجد **إلغاء** مع سبب واسم من ألغى، ليبقى الأثر.
